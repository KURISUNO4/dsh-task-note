# dsh-task-note

DSH 右上角的可拖动任务便签，取代 Web GUI 自带的任务列表。

## 功能

- **两栏任务**：`AI 任务` 读取当前会话的 `todos` 投影（`todo_write` 的实时结果）；`我的任务` 是便签自己的清单。
- **子任务**：每个用户任务左侧的 `>` 展开一层子任务清单；子任务同样支持新增、编辑、拖动排序、重要标记、圆圈完成即消失，并随主任务一起删除。
- **逐行编辑**：点任务文字就地编辑，回车保存，Esc 取消；底部输入框回车新增。
- **拖动排序**：拖每行右侧的六点手柄调整顺序（也支持 Alt+↑/↓）。
- **重要标记**：点行尾 `!` 切换；重要任务左侧有警示色竖线。
- **完成即消失**：点行首圆圈直接删除该任务，不再弹确认。
- **悬浮球**：标题栏右侧的收起按钮把便签缩成右上角悬浮球（带未完成数徽标）；拖动标题栏或悬浮球都能移动，位置与收起状态持久化。
- **浮动层级**：以 `popover="manual"` 放进浏览器顶层，避免被会话区的层叠上下文盖住。
- **替代原生列表**：以更低 priority 注册 `conversation.input.dock` 的 `todo` 槽位，原生任务面板不再出现。

## 安装

`plugin_manager` 的 `install_bundle` 指向本目录即可。Host 半侧为空，全部逻辑在 `client.js`。

## 数据

用户任务、位置、收起状态存在浏览器 localStorage 的 `dsh-task-note/v1`（按 Web GUI 源隔离）。AI 任务不落盘，始终来自会话投影。

## 已知限制

- 用户任务按浏览器源存储：桌面应用与普通浏览器各自一份。
- 子任务目前只支持一层：子任务行没有再次展开的 `>`，不能再往下嵌套。
- AI 任务只读；完成/修改仍需模型调用 `todo_write`。
- 便签位置按视口右上角锚定（`right`/`top`），窗口缩放时自动收进视口。
